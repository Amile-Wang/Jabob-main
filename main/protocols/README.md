# 捷宝宝 通信协议系统

## 概述

`protocols` 模块是捷宝宝 AI 聊天机器人项目的通信协议实现，提供了一个统一的协议接口和多种通信协议支持。该模块采用面向对象的设计模式，通过基类 [Protocol](file://z:\jabobo\Jabob-main\main\protocols\protocol.h#L43-L90) 抽象了所有通信功能，支持 MQTT 和 WebSocket 两种主流通信协议。

## 架构设计

### Protocol 基类 (protocol.h/cc)
- 定义了通信协议的统一接口
- 抽象了基本的通信操作方法
- 提供了连接管理、消息收发、状态回调等基础功能
- 所有具体的协议实现都继承自此基类

### MQTT 协议实现 (mqtt_protocol.h/cc)
- 基于 MQTT 协议的通信实现
- 支持 QoS 0、1、2 级别
- 实现了订阅/发布模式的消息传递
- 支持持久连接和断线重连
- 适用于物联网场景下的可靠通信

### WebSocket 协议实现 (websocket_protocol.h/cc)
- 基于 WebSocket 协议的通信实现
- 支持全双工实时通信
- 实现了二进制和文本消息传输
- 支持心跳机制和连接状态监控
- 适用于实时性要求较高的通信场景

## 功能特性

### 统一接口
- 所有协议实现相同的基础接口
- 应用层无需关心具体协议类型
- 支持运行时切换协议实现

### 消息管理
- 消息发送和接收功能
- 消息队列管理
- 发送确认和错误处理
- 消息格式标准化

### 连接管理
- 自动连接和重连机制
- 连接状态监控
- 心跳保活功能
- 断线检测和恢复

### 事件回调
- 连接建立/断开事件
- 消息到达事件
- 错误处理事件
- 状态变化事件

## 文件结构
protocols/

├── mqtt_protocol.h/cc # MQTT协议实现 
└── websocket_protocol.h/cc # WebSocket协议实现


## 使用方法

1. 根据应用场景选择合适的协议实现（MQTT 或 WebSocket）
2. 继承相应的协议类并配置连接参数
3. 实现消息处理和事件回调函数
4. 通过统一接口进行消息收发

## 扩展性

- 新增协议实现只需继承 [Protocol](file://z:\jabobo\Jabob-main\main\protocols\protocol.h#L43-L90) 基类
- 支持多种协议共存和动态切换
- 模块化设计便于功能扩展

## 选择建议

- **MQTT协议**：适用于物联网场景、低带宽环境、需要消息持久化的应用
- **WebSocket协议**：适用于实时性要求高的双向通信、Web集成场景

## 配置选项

- 连接地址和端口
- 认证凭据（用户名、密码）
- 客户端标识符
- 消息服务质量等级
- 心跳间隔和超时设置

## 注意事项

- 不同协议的资源占用和网络要求不同
- MQTT 需要专门的 Broker 服务器
- WebSocket 需要支持 WebSocket 的服务器
- 根据网络环境和可靠性要求选择合适的协议
